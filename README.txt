NEON CLICKER PWA

Файлы:
- index.html — главный экран
- styles.css — стили
- app.js — игровая логика
- manifest.json — настройки PWA
- sw.js — офлайн-кэш
- icons/ — иконки приложения

ВАЖНО:
PWA и Service Worker не работают корректно при обычном открытии файла через "Файлы" на iPhone.
Нужно разместить папку на HTTPS-хостинге.

После публикации:
1. Открой ссылку в Safari.
2. Нажми "Поделиться".
3. Выбери "На экран «Домой»".
4. Запускай Neon Clicker с иконки на главном экране.

Прогресс хранится в localStorage браузера/веб-приложения.
